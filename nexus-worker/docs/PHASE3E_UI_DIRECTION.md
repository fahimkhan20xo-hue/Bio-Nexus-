# Android AI screen: design direction (for Phase 3E, no Android change in Phase 3B)

Reference: a Gemini-like experience, clean and distraction-free, in BioNexus's own emerald identity.
(Two reference screenshots were mentioned in the request but did not arrive in the message I saw. This follows the written description.
Send them again before Phase 3E if exact look matters.)

- **Start screen:** clean dark background; small AI icon and a greeting in the middle; 2 to 3 useful suggested prompts; a simple chat input bar at the bottom. No cards, banners or extra information.
- **Answers:** small, quiet line at the end of each AI answer: "AI can make mistakes. Please verify important information."
- **Consent:** one short message before the first AI use; not shown again unless the policy version changes (see CONSENT_DRAFT.md).
- **Style:** emerald green accents, premium and simple. The existing offline Nexus stays the base; AI is an optional "Ask AI" step with the remaining daily count.
